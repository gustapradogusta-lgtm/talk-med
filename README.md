# MedTalk AI

Protótipo do CRM de recepção do consultório. Abra index.html no navegador para testar o funil, a triagem e o cadastro de profissionais.

O login e o WhatsApp são simulados. O navegador guarda os dados da demonstração. Use dados fictícios.

A integração com a Meta Cloud API, a autenticação real e o banco compartilhado ainda precisam ser implementados.
